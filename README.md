# Detecting Unsafe Reasoning Trajectories in Large Language Models

Research code and artifacts for **Detecting Unsafe Reasoning Trajectories in Large Language Models**, a comparative study of classic and LLM-based approaches for safety classification of reasoning traces.

The project addresses the **PAN-CLEF 2026 Reasoning Trajectory Detection** shared task. Given a user query and an intermediate reasoning trajectory generated by a large language model, the goal is to classify the trajectory into one of three labels:

* `safe`
* `potentially_unsafe`
* `unsafe`

Modern LLMs often expose step-by-step reasoning before producing a final answer. Even when the final answer appears benign, the intermediate reasoning trajectory may still contain harmful or unsafe content. This repository explores methods for detecting such unsafe reasoning trajectories.

## Overview

We compare three families of approaches:

1. **TF-IDF + SVM** as a classic machine learning baseline
2. **BERT fine-tuning** as an encoder-based deep learning baseline
3. **Decoder LLMs with LoRA adapters and a classifier head**

The evaluated decoder LLM backbones are:

* Qwen3-0.6B
* Llama-3.2-1B
* Mistral-3B-Instruct
* Phi-4-mini-Instruct

The best-performing model is **Phi-4-mini + LoRA (r=64)**.

The experiments use the **PAN-CLEF 2026 Reasoning Trajectory Detection** dataset.

Dataset split used in the experiments:

| Split                          | Examples |

| Training set                   |    7,000 |
| Internal training split        |    6,300 |
| Internal validation split      |      700 |
| Official validation / test set |    2,200 |

The official validation set was treated as the test set, since the official test labels were withheld during experimentation.

## Methods

### TF-IDF + SVM

A classic baseline using TF-IDF features and a linear SVM classifier.

This model establishes a minimum performance reference, but it does not model word order, long-range dependencies, or semantic reasoning patterns.

### BERT Fine-Tuning

BERT models were fine-tuned with a classification head over the `[CLS]` token.

BERT improves over the classic baseline, but its 512-token context limit causes significant truncation for long reasoning trajectories.

### Decoder LLMs + LoRA

Decoder-only LLMs were adapted using **LoRA** on the attention projection matrices:

* `q_proj`
* `k_proj`
* `v_proj`
* `o_proj`

A two-layer MLP classifier head was trained over the mean-pooled hidden states of the final transformer layer.

The following LoRA ranks were evaluated:

```text
r ∈ {4, 16, 32, 64}
```

---

## Key Findings

* LLMs with LoRA adapters significantly outperform TF-IDF, SVM, and BERT-based baselines.
* Phi-4-mini performs best, likely due to its reasoning-focused pretraining.
* The optimal LoRA rank depends on model size:

  * Qwen3-0.6B performs best at `r=16`
  * Larger models perform best at `r=64`
* The `potentially_unsafe` class remains the hardest to classify.
* Very long reasoning trajectories can dilute unsafe signals when using mean pooling.
* Integrated Gradients analysis shows that models can detect unsafe query-level signals, but may still be misled by superficially cautious or hedging reasoning steps.

## Disclaimer

This repository is intended for research and educational purposes.

The models and methods presented here should be used as first-pass safety analysis tools and not as fully autonomous moderation systems. Borderline cases, especially those classified as `potentially_unsafe`, should be reviewed by humans.
